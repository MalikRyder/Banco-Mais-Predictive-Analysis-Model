## Project Overview
Used the CRISP-DM approach to build a predictive model in Excel that identifies which customer segments are more likely to subscribe to a term deposit in future marketing campaigns.



## Business Question

Which customer segments should Banco Mais target in future marketing campaigns to increase term deposit subscription rates?



## Tools & Techniques Used

- Microsoft Excel
- Pivot Tables
- Descriptive Statistics
- Regression Analysis
- Data Visualization



## Data Preparation 

- Checked the dataset for data errors and missing values
- Verified and formatted each variable using the appropriate data type
- Used descriptive statistics to evaluate the center, balance, and spread of numerical variables
- Compared independent categorical variables against the baseline term deposit subscription rate to identify potential patterns



## Exploratory Data Analysis

- Identified key independent variables for further analysis, including customer job type, account balance, and education level
- Explored relationships between these variables and term deposit subscriptions
- Developed hypotheses based on patterns identified during the exploratory analysis
- Built mini-models to test the hypotheses and determine which relationships were worth investigating further
  


  ## Feature Engineering
  
- Created account balance bins to group customers into low, medium, and high balance categories
- Coded education levels into categories to analyze differences in term deposit subscription rates
- Coded customer job types to analyze subscription patterns across different occupations
- Prepared categorical variables for use in the predicitve model



## Predictive Modeling

- Performed regression analysis to evaluate the relationships between customer characteristics and term deposit subscriptions
- Evaluated P-values to determine which variables were statistically significant
- Used the significant variables to help identify customer segments associated with higher subscription rates
- Evaluated the model's overall performance and suitability for the business problem
